# 数学公式

行内公式：质能方程 $E = mc^2$，以及一个带花括号的 $\frac{a}{b} + \sqrt{x}$。

块级公式：

$$
\int_{0}^{\infty} e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}
$$

下面这些 `$` **不是**公式，导出时必须原样保留：

- 行内代码里的：`echo $PATH` 和 `$HOME/bin`
- 价格：这件 $19 那件 $25
- 变量名：$foo 单独出现

```bash
# 代码块里的美元符号同样不能被当成公式
export PRICE=$100
echo "$USER owes $PRICE"
```

| 列 | 含义 |
| --- | --- |
| $x$ | 表格单元里的行内公式 |
| `$y$` | 表格单元里的代码，不是公式 |
