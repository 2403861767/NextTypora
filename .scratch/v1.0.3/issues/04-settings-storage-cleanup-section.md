# V103-04: 设置弹窗新增「存储」区块：清理旧备份目录

Status: ready-for-agent
Type: Change
Commit prefix: `Change V103-04:`
Spec section: 3（见 ../spec.md）

## 改动

递归扫描**当前工作区**，列出所有 `.nexttyproa-backups/`，显示「找到 N 个目录、共 X MB」，用户确认后整体移到系统回收站（复用 `file:trashItem`）。

三条约束：

1. 只扫当前工作区，不碰用户别的磁盘位置
2. 先报数再动手，用户看得见要删什么
3. 走回收站，可撤销

**不做首次启动自动弹窗**——升级后第一次打开就被质问「要不要删你的文件」，观感像流氓软件。

## 验收

扫描结果为 0 时按钮给出明确反馈而非静默；确认后目录进回收站而非永久删除。
