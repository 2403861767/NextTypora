# 缺陷史归档

这两份清单记录了 NextTypora 1.0.0–1.0.2 期间发现并修复的全部 54 个缺陷。

- [`BUG_BACKLOG.md`](BUG_BACKLOG.md)：27 条（`BUG-P0-001` … `BUG-P2-015`），代码审查与单元测试发现的问题。
- [`BUG_BACKLOG_REAL_WORLD.md`](BUG_BACKLOG_REAL_WORLD.md)：27 条（`RW-P0-001` … `RW-P3-006`），真实场景端到端测试发现的问题。

**两份里未关闭条目都是 0**，全部已修，每条都能在 `git log` 里找到对应的 `Fix Bug-` 提交。

## 为什么把它们放回来

这两个文件在 `ba867ca`（v1.0.2）被整体删除、并写进了 `.gitignore`，于是项目踩过的全部坑只能靠 `git show ba867ca^:<file>` 才能挖出来。1.0.3 做盘点时发现：`CLAUDE.md` 里那些「⚠️ 关键安全规则」的**理由**就写在这两份文件里——规则本身已经脱离了证据，而脱离证据的规则迟早会被当成多余的东西删掉。

它们覆盖的坑包括编码检测（GBK/Big5/Shift-JIS/UTF-16/BOM）、路径穿越、per-path 锁、孤儿进程、标签页恢复、frontmatter 保全等，是这个产品密度最高的上下文。

## 这不是待办清单

当前版本的待办在 [`.scratch/v1.0.3/`](../../.scratch/v1.0.3/)。这里只放已完结的历史，**不要往里加新条目**。

`BUG_BACKLOG_REAL_WORLD.md` 末尾的「未能覆盖 / 测试局限」一节是个例外：它列出的未测项（原生对话框、`.md` 文件关联、真实输入法、资源管理器拖拽、PicGo、多显示器、打印、Alt+F4 等）至今仍然有效，是 `V103-17` 打包版复测的唯一现成依据。
