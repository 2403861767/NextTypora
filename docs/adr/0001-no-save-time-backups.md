# 保存时不做备份

Status: accepted

应用曾在每次保存已存在的笔记时，往同目录的 `.nexttyproa-backups/` 复制一份带时间戳的副本，每篇笔记保留 10 份。我们在 1.0.3 移除了它：全仓库没有任何代码**读取**这些副本，所以它只产生垃圾而不提供恢复能力——用户唯一能感知到它的方式是硬盘变大。真正的数据防线是另外两条：应用之外的改动走可见的冲突副本，删除走系统回收站。

## Consequences

这是一个刻意的「不做」，不是遗漏。`CLAUDE.md` 曾把「覆盖前创建 `.bak` 备份」列为不可违反的关键安全规则，该条已随此决定改写——**不要因为看到「原子写 + 编码保留」的上下文就把备份加回来**。

如果将来要做版本历史，正确形态是可浏览、可对比、可回滚的功能，而不是恢复这个只写不读的目录。
